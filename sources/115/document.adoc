.Foreword
This document is part of the Metanorma specifications series that defines
requirements for internationalized document rendering, specifically addressing
punctuation usage across multiple languages and writing systems.

== Introduction

Metanorma is a semantic authoring system that supports multiple languages and
the publication of multi-lingual output.

Support of semantic representation using native punctuation in their respective
languages is essential for the accurate portrayal of information and to meet
cultural and linguistic expectations.

This document defines a framework for semantic punctuation usage across multiple
languages and writing systems.

The document covers the following languages and writing systems:

* Traditional Chinese (Taiwan/Hong Kong conventions)
* Simplified Chinese (Mainland China conventions)
* Japanese (including vertical text layout)
* Korean (Hangul-specific rules)
* (informative) Latin-script languages (English, Spanish, French, Russian, etc.)

The document defines punctuation marks into primary usage categories based
on the semantic function of the punctuation symbols.

This document addresses critical challenges including:

Internationalization of auto-numbered elements::
Applying appropriate punctuation to document elements, such as: clauses, lists,
figures, tables and references use. Enabling definition of Label Auto-assignment
Definition Language profiles (LADL) (<<MN112>>).

Internationalization of bibliographic citations::
Applying appropriate punctuation to in-text citations and reference lists,
allowing for citation style definition and language-specific variations.

Automatic spacing::
Applying appropriate whitespace around punctuation marks based on
language-specific rules.

Rendering in vertical text layouts::
Proper punctuation positioning and transformation in vertical text modes.

== Terms and definitions

=== punctuation mark

symbol used in written language to clarify meaning, indicate pauses, separate
elements, or convey syntactic relationships

=== usage category

functional classification of punctuation marks based on their primary purpose in
text structure

[example]
====
Sentence delimiters, pause indicators, grouping markers.
====

=== language variant

specific form or application of a punctuation mark that differs between
languages or writing systems

[example]
====
Period: "." (Latin) vs "。" (CJK)
====

=== full-width character

character that occupies the width of two half-width characters, commonly used in
East Asian typography

=== half-width character

character that occupies standard Latin character width, used in Western
typography and mixed East Asian text

=== vertical text layout

text arrangement where characters flow from top to bottom in columns arranged
from right to left, traditional in East Asian documents

=== spacing rule

specification for whitespace insertion around punctuation marks that varies by
language and context


== Framework

This framework provides guidelines for the consistent application of punctuation
marks across different languages and writing systems. It aims to ensure that
punctuation usage aligns with semantic meaning and cultural conventions.

Punctuation profile:: A set of rules and mappings that define how punctuation
marks are applied in a specific language or document context. Even in the same
language, different publishers may require different punctuation styles.
+
[example]
====
In Japanese, the
https://www.bunka.go.jp/seisaku/bunkashingikai/kokugo/hokoku/pdf/93651301_01.pdf[「公用文作成の考え方」（建議）（付）「公用文作成の考え方（文化審議会建議）」解説] of
the Agency for Cultural Affairs (2022) specifies different punctuation rules
from JIS X 8301:2019, the Japanese Industrial Standard stating requirements for
punctuation in Japanese standards:

* sentence pausal mark: the former requires use of the "ten" `、` but the latter
requires the use of the full-width western "comma" `，`.
====

Punctuation mark:: A symbol used in writing to clarify meaning, indicate pauses,
separate elements, or convey syntactic relationships. Each punctuation mark has
a specific semantic function that may vary across languages. Not all marks
exist in all languages. A mark is commonly represented by one or more glyphs.

Semantic function:: The primary purpose or role of a punctuation mark in text,
which may include indicating sentence boundaries, pauses, grouping, emphasis,
indicating relationships, semantic indication such as for named elements.
+
[example]
====
The semantic function of "sentence pause" is represented by
different punctuation marks in different languages:

* Japanese: `、` (full-width "ten")
* Chinese: `，` (full-width comma)
* English: `,` (half-width comma)
====
+
Not all semantic functions exist in all languages.
+
[example]
The semantic function of "enumeration delimiter" used in
Traditional Chinese and Simplified Chinese does not exist in English or
Japanese.


Punctuation rule:: A guideline that specifies how a punctuation mark should be
used in a particular language or context, including placement, spacing, and
variations. A semantic function may be represented by different punctuation
marks in different languages.

A punctuation profile is defined by:

* A set of semantic functions that apply to semantic elements in text
* Punctuation marks that are associated with each semantic function
* A collection of punctuation rules that govern their usage

Given a punctuation profile, a document rendering with appropriate punctuation
that suits the target audience can be achieved.


== Punctuation semantic functions

=== General

Punctuation marks are classified into semantic function categories.

=== Sentence stops

==== Declarative stop

Mark that indicates the end of a complete grammatical statement.

[cols="2,2,2,3"]
|===
|Language |Name of Mark |Symbol |Example

|English
|period
|`.`
|This is a sentence.

|Traditional Chinese
|句號
|`。`
|這是一句句子。

|Simplified Chinese
|句号
|`。`
|这是一句句子。

|Japanese
|句点
|`。`
|これは文です。

|Korean
|마침표
|`.`
|이것은 문장입니다.

|===

[NOTE]
====
Full-width vs half-width selection:

* CJK languages: Use full-width forms (。？！) in native text
* Latin languages: Use half-width forms (. ? !) with standard spacing
* Mixed text: Follow primary language of the sentence

Spacing rules:

* No space before sentence delimiters in any language
* Space after delimiter when followed by same-script text
* No space after delimiter at paragraph end

Vertical text handling:

* Period (。) remains in same position
* Question mark (？) and exclamation mark (！) remain in same position
* No rotation required for CJK sentence delimiters
====

== Punctuation categories

=== General principles

Punctuation marks are classified by their primary functional usage rather than
their linguistic origin.

This approach enables consistent implementation across different languages while
accommodating language-specific variations within each functional category.

Each usage category defines:

* Primary function and purpose
* Common mark variations across languages
* Spacing requirements
* Special handling rules
* Integration with auto-numbering systems

// Enumeration comma handling::::
// * Japanese: Use 、 for list items, ， for clause separation
// * Chinese: Use 、 for list items, ， for clauses
// * Latin languages: Use , for both functions with context-dependent spacing

// French spacing rules::::
// * No space before regular comma (,)
// * Required space before semicolon ({nbsp};)
// * Thin space preferred in professional typography

// Mixed-language lists::::
// When lists contain mixed scripts, follow the punctuation convention of the list's primary language while maintaining readability.
